# Widgy iPhone Status

Repository for the premium Widgy iPhone Status widget.

## Structure

- `assets/draft/` — working PNG assets that still need on-device visual approval.
- `widget/source/` — untouched source Widgy JSON backup.
- `widget/builds/` — future tested/final Widgy builds.

## Current status

The battery ring and tile frame in `assets/draft/` are technical PNG builds.
They should remain marked as drafts until they are confirmed visually in Widgy.
